# Customer Margin Dashboard

Dashboard executivo para visão de clientes, receita, custos e margem de lucro.

## MVP
- KPIs de receita, custo, lucro bruto e margem
- Evolução mensal
- Margem por cliente vs. meta de 30%
- Ranking de rentabilidade
- Filtros por período, cliente e segmento
- Indicadores de clientes acima da meta, em atenção e críticos
